### History
Древние египтяне прославились, построив свои пирамиды. А вы можете прославиться, разрушив до основания в пасьянсе карточную пирамиду и очистив игровое поле. И дополнительно получить бонус в подарочной коробке – тот, который вам приглянется. Но вооружаться молотком, ломом и прочей грубой техникой не стоит – используйте в качестве инструмента свои знания математики. Ведь считать до 13 вы умеете? И знаете, из каких цифр можно получить в сумме 13? Тогда за работу!
Разрушьте до основания древнее египетское сооружение, играйте бесплатно в пасьянс Пирамида онлайн, делитесь своими результатами!

## Как играть
Числовые значения карт: Король = 13, Дама = 12, Валет = 11, Туз = 1, остальные карты соответствуют написанным на них цифрам.
Карты снимаются парами, сумма должна составлять 13 – ни больше, ни меньше. Исключение – король снимается с игрового поля в гордом одиночестве.

Pyramid
Современное веб-приложение, построенное на базе React и Vite. Проект использует Redux Toolkit для управления состоянием и FontAwesome для работы с иконками.

🛠 Технологический стек
Core & State Management
React (v18.2.0): Основная библиотека для разработки интерфейса.

Redux Toolkit (v2.2.3): Современный подход к управлению глобальным состоянием приложения.
React Redux: Официальная библиотека связки Redux и React.
React Router DOM (v6.22.3): Организация навигации и маршрутизации.

UI & Icons
FontAwesome (v6.5.2): Обширная библиотека иконок (Solid, Regular, Brands), интегрированная через официальный компонент для React.

Сборка и Инструментарий
Vite (v5.2.0): Быстрый инструмент сборки и сервер для разработки.

ESLint: Статический анализатор кода с плагинами для React и Hooks для поддержания чистоты кода.

gh-pages: Настроенный инструмент для автоматического деплоя приложения.

🚀 Скрипты для разработки
В проекте доступны следующие команды:

npm run dev — запуск локального сервера разработки (Vite).

npm run build — сборка проекта в папку dist для продакшена.

npm run preview — локальный просмотр собранного production-билда.

npm run lint — запуск проверки кода через ESLint.

npm run deploy — автоматическая сборка и публикация проекта на GitHub Pages.

📦 Особенности конфигурации
Vite Plugin React: Использование Fast Refresh и оптимизаций для React-компонентов.

Static Copy: Настроено копирование статических файлов при сборке через vite-plugin-static-copy.

ES Module: Проект настроен как модуль ("type": "module").
